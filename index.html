03 / PORTFOLIO

PROJECT_01

ARTISTAPP

ArtistApp es una plataforma web que reúne en un mismo lugar una red social creativa, una agenda de eventos y una tienda para artistas. La aplicación se ha reconstruido con un frontend en Angular y una API REST en Laravel, conservando compatibilidad con el esquema histórico de MySQL. El objetivo es ofrecer a cada persona un espacio donde mostrar su trabajo, descubrir nuevos creadores y participar en una comunidad artística.

SECOND HAND

SecondHand es una aplicación web de compraventa de productos de segunda mano, desarrollada con Angular en el frontend y Java Spring Boot en el backend.
